CodUI Documentation

A zero-dependency, ultra-lightweight Web Component (<cod-ui>) for code syntax highlighting with isolated Shadow DOM styling, built-in line numbers, multiple themes, and one-click clipboard copy.

💡
Zero Configuration Required Just drop one <script> tag and use <cod-ui> anywhere in your HTML, React, Vue, Svelte, or static pages.

Quick Start

Add the script from CDN and immediately place the custom element in your document:

const calculateTotal = (items) => { return items.reduce((acc, curr) => acc + curr.price, 0); }; console.log(calculateTotal([{ price: 29.99 }, { price: 49.99 }]));

Component Attributes API

CodUI is configured declaratively using HTML attributes on the <cod-ui> element.

Attribute Type Default Description
lang string 'js' Language syntax rules to apply. E.g. js, ts, python, html, css, json, bash.
theme string 'dark' Color theme applied inside the Shadow DOM: dark, light, dracula, or glass.
line-numbers string 'false' Pass 'true' to render an un-selectable gutter line number column.
width string '100%' CSS width value applied to the outer code window frame (e.g. 100%, 680px).
height string 'auto' CSS max-height value. If specified, overflowing code creates an internal scrollbar.

JavaScript API & Programmatic Use

CodUI exposes both static highlighting methods and Web Component instance methods.

Static Highlighting Method: CodUI.highlight()

You can generate highlighted HTML strings directly without rendering a custom element DOM tree:

// Access the Custom Element constructor const highlightedHTML = customElements.get('cod-ui').highlight( 'const author = "CodUI";', 'js' ); console.log(highlightedHTML); // Output: 'const author = "CodUI";'

Dynamic Attribute Mutation

Because CodUI registers observedAttributes, modifying attributes dynamically triggers instant re-renders:

const el = document.querySelector('cod-ui'); // Switch theme dynamically el.setAttribute('theme', 'glass'); // Toggle line numbers el.setAttribute('line-numbers', 'false');

Shadow DOM & Styling Isolation

CodUI encapsulates all of its styling inside an open Shadow DOM. This means:

  • Your global page CSS (e.g. Bootstrap, Tailwind, normalize.css) will never leak inside or break the code block's typography or button styles.
  • CodUI's internal syntax colors will never collide with your existing .keyword or .string classes.

Troubleshooting & FAQ

❓
Why did my arrow function => turn into =&gt;? In versions prior to v2.0.9, innerHTML parsing could cause double-escaping. Upgrade to v2.1.0 which uses direct textContent extraction to completely eliminate double-escaping.
❓
Why did Python hash strings like '#' turn green as comments? In early versions, the comment regex ran prior to string matching. In v2.1.0, a single-pass alternation ensures strings take precedence, correctly preserving hash characters inside quotes.
❓
Does CodUI require any bundler or build step to use? No! It is written in pure vanilla JavaScript and utilizes native standard Web Components supported in 100% of modern browsers (Chrome, Safari, Firefox, Edge).
