What's inside

Everything you need.
Nothing you don't.

Built from the ground up for modern web development. CodUI provides professional-grade syntax highlighting without the bloat, designed to scale with your project.

Zero Dependencies
Pure native Web Component using Shadow DOM. No React, no Vue, no build tools. Drop the script tag and you're done. Completely isolated styling prevents CSS bleed.
Multi-Theme Support
Built-in dark, light, dracula, and glass themes. Switch with a single attribute. Decoupled CSS-driven theme engine makes adding custom themes trivial.
Line Numbers
Optional toggleable line number column. Styled, aligned, non-selectable by default. Automatically counts lines and adjusts layout to fit perfectly.
Copy Button
Interactive one-click copy with visual confirmation. Smart text selection ensures you only copy the raw code, completely ignoring line numbers and UI elements.
Fully Responsive
Customizable width and max-height attributes. Beautiful custom scrollbars on overflow. Works flawlessly in flexbox, grid, and standard document flows.
Multi-Language
JS, TS, Python, HTML, CSS, JSON and bash. Robust Regex engine prevents tokenizer collisions. Graceful fallback rendering for unknown languages.

Get Started

Up in 60 seconds.

From zero to beautiful syntax highlighting in under a minute. Three simple steps is all it takes.

01
Install via npm
Add CodUI to your project using your package manager of choice. The footprint is tiny and it has exactly zero dependencies.
npm install cod-ui
02
Import the script
Import the component once in your application's entry file. The custom element registers itself with the browser automatically.
import 'cod-ui';
03
Use the tag anywhere
Wrap your raw code blocks in the <cod-ui> tag. The component will parse, highlight, and render it beautifully.
<cod-ui lang="js" theme="dark">...</cod-ui>
